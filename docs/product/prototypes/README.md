# Prototypes métier

## Prototype de validation métier DossierClé

Fichier autonome : [prototype-validation-metier-dossiercle.html](prototype-validation-metier-dossiercle.html).

Il présente une maquette interactive avec des données fictives. Les modifications
sont conservées dans le stockage local du navigateur (`localStorage`) ; aucune
API ni aucun envoi réel n’est utilisé. Ce prototype illustre des parcours et ne
remplace pas les décisions produit ni la spécification du [Design System](../DESIGN_SYSTEM.md).
